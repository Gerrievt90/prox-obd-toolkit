# ProX OBD Toolkit

Personal multi-make OBD diagnostics for phone and Android car stereo.

## Open without a server (no webserver needed)

1. Download **ProX-OBD-Toolkit.html** from this repo
2. Copy it to your phone or Android head unit (USB, Drive, email, etc.)
3. Open it in **Chrome**
4. Tap **Connect → Demo mode** to explore every screen

## Live HTTPS (needed for real Bluetooth OBD)

Enable **Settings → Pages → Deploy from branch `main` / root**.

Then open: https://gerrievt90.github.io/prox-obd-toolkit/

Bluetooth adapters need HTTPS. Demo mode works offline from the HTML file alone.

## Features

- Live data gauges, DTCs (including permanent), TPMS, key fob guidance, bi-directional controls
- **CAR** mode + **NIGHT** mode for head units
- Personal use only on vehicles you own
